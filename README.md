# San Martín Portal

Build the homepage prototype for Club San Martín following the attached design.md as the primary source of truth for architecture, visual direction, colors, typography, components, motion, accessibility, responsive behavior, and content tone.

The entire user-facing website must be written in Spanish.

I am also attaching these club assets:

sanMartinLogo.svg

sanmartin-01.jpg

sanmartin-02.jpg

sanmartin-03.jpg

Use them as follows:

sanMartinLogo.svg: use it as the official club logo throughout the interface, especially in the Header, Hero, and Footer. Preserve its original proportions and brand colors. Do not redraw, reinterpret, recolor, or replace it with a generated logo.

sanmartin-01.jpg, sanmartin-02.jpg, sanmartin-03.jpg: use these real club photos as the initial imagery for the Featured News carousel. Crop them responsively when necessary, but preserve their visual quality and do not apply aggressive filters that alter the club's blue and yellow identity.

For any other image slot described in design.md for which no real asset has been provided yet, use a tasteful temporary placeholder or reuse an appropriate supplied club image when it makes visual sense. Do not introduce generic football stock photography as if it were real Club San Martín content.

The prototype should focus only on the homepage for now. Internal CTAs can point toward future routes/pages, but those pages do not need to be fully implemented in this iteration.

Prioritize the main conversion objective:

Hacete socio

The homepage must communicate Club San Martín as a serious neighborhood football institution centered around:

formación, semillero, comunidad, oportunidades, barrio y futuro.

Use the real club assets to make the prototype feel authentic rather than like a generic football template.

Implement the design with a polished responsive layout and the controlled, dynamic sports motion system defined in design.md. Avoid adding visual styles, sections, gradients, effects, or design patterns that contradict the document.
